# BloodConnect – Blood Donor Management System

BloodConnect is a web-based Blood Donor Management System developed to connect blood donors with people who need blood during medical emergencies. The main aim of this project is to make blood donor registration, blood group searching, and blood request management easier and faster.

The system allows donors to register by providing their personal details, blood group, and location. Users can search for available donors based on blood group and city. Patients or their family members can also submit blood requests by entering hospital details, required blood group, number of units, and emergency level.

Google Sheets is used as the database to store donor registrations and blood requests, while Google Apps Script handles the backend operations and connects the website with the database.

## Technologies Used
- Google Apps Script – Backend development
- HTML – Website structure
- CSS – Website styling
- JavaScript – Frontend functionality
- Google Sheets – Database management

## Key Features
- Donor Registration
- Blood Group Search
- Location-Based Donor Search
- Blood Request Submission
- Emergency Level Selection
- Dashboard Statistics
- Google Sheets Database Integration

## Project Objective
To develop a simple and user-friendly platform that helps people find potential blood donors quickly and makes blood donation information easier to manage.
